# Atlas Adventures

Site vitrine de treks guidés dans le Haut Atlas (Maroc), réservation par WhatsApp.

En ligne : https://yanis-belfkih.github.io/Atlas-Adventure/

## Stack

Next.js (export statique), React, TypeScript, Tailwind CSS.

## Démarrage

```bash
npm install
npm run dev
```

`npm run build` génère le site statique dans `out/`. Le déploiement sur GitHub Pages se fait automatiquement à chaque push sur `main`.
